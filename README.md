Learning Management System (LMS)

Overview-------

This project is a Learning Management System (LMS) built to simplify online education and course management. It provides a comprehensive platform for students, instructors, and administrators, enabling seamless learning and teaching experiences.

Features-------

For Students Registration & Enrollment: Students can register and enroll in available courses.

Access Course Content: View detailed course materials, including videos, documents, and assignments.

For Instructors Login & Course Publishing: Instructors can log in to their accounts and publish courses.

Content Management: Easily upload and manage course materials.

For Admin Full Control: Admin has full control over:
Courses, Students, Instructors, All content

User Management: Add, remove, or update users (students and instructors).

Course Management: Approve, edit, or delete courses and their content.

Technologies Used--------

Frontend:

React: User interface and dynamic components.

Material-UI (MUI): Responsive and modern UI components.

Backend:

Node.js: Server-side logic.

Express.js: API routing and backend functionality.

MongoDB: Database for storing user data, courses, and content.

Authentication

JWT (JSON Web Tokens): Secure user authentication.

Others------

Cloudinary: Media storage for course content.

Multer: File uploads for course materials.
